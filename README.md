# Movie Big Data Lab Final

This repository contains the final project for the Big Data lab focused on movie analytics using Hadoop, MapReduce, and Pig.

## Project structure

- `mapreduce/` — Java MapReduce implementations for the movie analysis problems
- `PigAnalysis/` — Pig scripts and generated output files
- `hdfs/` — Hadoop distributed file system input/output folders
- `dataset/` — local dataset files used for analysis

## Included work

- Movie keyword analysis
- Top keywords analysis
- Most popular movies analysis
- Top revenue movies analysis
- Pig-based movie analytics by decade, genre, popularity, and revenue

## Tools used

- Hadoop
- MapReduce
- Apache Pig
- Java
- CSV data processing

## Repository purpose

This repository is intended to store the implementation and outputs for the Big Data lab assignment on movie dataset processing.

## Notes

- The dataset file is intentionally excluded from source tracking due to size limitations.
- This project is meant for academic/demo purposes.
